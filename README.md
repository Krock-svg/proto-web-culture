# 🏛️ Pesona & Khazanah Budaya Magelang

Portal interaktif edukasi budaya dan panduan pariwisata Magelang dengan arsitektur **Dual-Mode** (*Mode Mahasiswa* & *Mode Umum*), dibangun menggunakan **HTML5**, **Tailwind CSS**, dan **Vanilla JavaScript**.

---

## 🌟 Fitur Utama

### 🎓 1. Mode Mahasiswa (Kajian Akademik & Riset Budaya)
Dirancang khusus untuk civitas akademika dan mahasiswa perguruan tinggi:
- **Kategori Mata Kuliah**:
  - *Arkeologi & Sejarah*: Dekonstruksi kosmologi Candi Borobudur, Prasasti Mantyasih (907 M), & Prasasti Canggal (732 M).
  - *Antropologi & Seni Pertunjukan*: Tari Soreng lereng Merbabu & Kesenian Topeng Ireng lereng Menoreh.
  - *Arsitektur Vernakular*: Omah Joglo Magelangan & sambungan tumpangsari tahan gempa.
  - *Sosiologi & Kearifan Lokal*: Sistem mitigasi erupsi Merapi berbasis *Sister Village* (Paseduluran Desa).
- **Salin Sitasi Otomatis (One-Click Citation)**: Mendukung format sitasi standar karya ilmiah (APA 7th & Chicago).
- **Catatan Riset Saya (Bookmarks)**: Menyimpan artikel kajian ke penyimpanan lokal browser (`localStorage`).
- **Mode Cetak / Simpan PDF**: Tampilan ramah cetak (`@media print`) untuk bahan rujukan tugas kuliah.

### 🌍 2. Mode Umum (Panduan Pariwisata & Budaya Populer)
Dirancang untuk wisatawan domestik, mancanegara, dan masyarakat umum:
- **Destinasi Wisata**: Informasi tiket, jam operasional, peta Google Maps untuk Borobudur, Nepal Van Java, Punthuk Setumbu, Ketep Pass, Svargabumi, dan Candi Umbul.
- **Pilihan Tour Guide**: Profil pemandu wisata berlisensi resmi HPI Magelang, spesialisasi bahasa asing, dan tombol direct chat WhatsApp.
- **Penginapan & Hotel**: Rekomendasi resort bintang 5 hingga homestay desa wisata otentik (Desa Wisata Candirejo).
- **Edukasi Budaya & Kuliner**: Legenda Gunung Tidar, kamar pengasingan Pangeran Diponegoro, serta kuliner ikonik Kupat Tahu, Mangut Beong, Sop Senerek, dan Getuk Trio.
- **Sentra UMKM Sekitar Wisata**: Pahat batu candi Muntilan, gerabah Klipoh, batik Magelangan, dan kopi lereng Menoreh.

## 🛠️ Teknologi yang Digunakan
- **HTML5**: Struktur semantik & aksesibilitas web.
- **Tailwind CSS**: Desain modern responsif, skema warna warisan budaya (*academic indigo*, *emerald nature*, *terracotta*, *batik gold*).
- **Vanilla JavaScript**: Tanpa framework berat, modular, cepat, dan kompatibel langsung melalui `file://` maupun `http://`.
- **Font Awesome 6 & Google Fonts**: Tipografi Plus Jakarta Sans & Merriweather.

## 🚀 Cara Menjalankan

### Cara 1: Langsung Buka Berkas (Tanpa Instalasi)
Cukup klik dua kali berkas **`index.html`** di komputer Anda. Web akan langsung berjalan secara offline dan online.

### Cara 2: Menggunakan Local Web Server
Jika Anda memiliki Python terinstal:
```bash
# Jalankan server lokal
python -m http.server 5173
```
Buka browser dan akses: `http://localhost:5173`
